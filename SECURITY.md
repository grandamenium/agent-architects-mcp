# Security Policy

## Supported Version

The hosted production MCP server at `https://aa-mcp-server-production.up.railway.app/mcp` is the supported version.

## Reporting Security Issues

Do not open a public issue containing secrets, API keys, bearer tokens, Supabase credentials, Railway tokens, OpenAI keys, private member data, or raw Skool exports.

If you believe a key leaked, rotate it immediately and notify the Agent Architects admins inside the community.

## Key Handling

- Treat your Agent Architects MCP key like a password.
- Do not paste keys into GitHub issues, screenshots, livestreams, or public chats.
- Public docs use `<YOUR_AA_MCP_KEY>` placeholders only.
- The real shared key is distributed through member-only Agent Architects channels.

## Data Access

This MCP server is read-only. It searches an indexed copy of Agent Architects knowledge and cannot modify Skool accounts, community posts, comments, or member profiles.
