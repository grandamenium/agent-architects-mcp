# API Key Policy

Agent Architects MCP access currently uses a shared community bearer key.

## Members

- Get the key from the pinned Agent Architects post or MCP setup lesson.
- Keep the key private.
- Do not post it in GitHub issues or public chats.
- If the key stops working, check the community for a rotated key.

## Maintainers

- Rotate the shared key if it leaks.
- Keep public docs on placeholders only.
- Never commit the real key.
- Consider moving to per-member keys after the initial public launch if abuse, attribution, or revocation needs increase.
