# Launch Copy

## Public GitHub Copy

Agent Architects MCP lets your AI client search Agent Architects lessons, posts, comments, and member profiles directly.

Install it in Claude Desktop, Claude Code, Cursor, Windsurf, or any MCP client that supports remote HTTP servers.

Use this endpoint:

```text
https://aa-mcp-server-production.up.railway.app/mcp
```

Get your key from the pinned Agent Architects post or the MCP setup lesson inside the community.
