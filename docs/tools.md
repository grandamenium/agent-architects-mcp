# Tools

## `search_knowledge_base`

Use this for broad discovery across Agent Architects lessons, posts, comments, and member profiles.

Example:

```text
Search Agent Architects for lessons and posts about evals.
```

Best for:

- Conceptual questions.
- Finding related lessons and community discussion.
- Open-ended research.

## `get_lesson`

Use this when you want one exact classroom lesson.

Example:

```text
Get the Claude Code Fundamentals lesson on context engineering.
```

Best for:

- Exact course or lesson requests.
- Avoiding broad semantic-search bleed.

## `search_members`

Use this when you want to find people in the community by niche, skill, background, or use case.

Example:

```text
Which members should I meet if I run a marketing agency and want to implement AI?
```

Best for:

- Finding collaborators.
- Finding experts.
- Finding members with similar businesses or goals.

## `get_member`

Use this when you know a member handle or name and want their profile.

Example:

```text
Look up @roberto-cellini-6004 in Agent Architects.
```

Best for:

- Exact member lookup.
- Member profile summaries.
- Optional recent activity context when the client asks for it.
